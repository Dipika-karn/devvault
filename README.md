# DevVault

DevVault is a developer-resource management application designed to bring useful coding and learning resources into one organized place.

## Current Features

- Responsive landing page
- Layout designed for desktop and mobile screens
- Project structure built with Next.js and React

## Planned Features

- Organize GitHub repositories, tutorials, documentation, and articles
- Save personal notes and code snippets
- Search and categorize resources
- User authentication
- Personalized resource dashboard

## Tech Stack

- Next.js
- React
- JavaScript
- Tailwind CSS
- MongoDB and Mongoose (planned or in development, as applicable)
- Auth.js / NextAuth (depending on the current implementation)

## Getting Started

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Configure the required environment variables in a local `.env.local` file.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

Check the project configuration for the exact environment variables required. Never commit real credentials or secrets.

## Project Status

**In Development**

DevVault is being developed as a portfolio project to practise frontend development, authentication, database integration, and resource management.

Features listed as planned are not yet complete.
